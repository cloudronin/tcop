# Agent study findings

This artifact is intentionally incomplete because one or more pre-registered live gates did not pass; no study setting was tuned.

- Model willingness is counted only by eligible captured tool traces.
- Gateway effectiveness is measured only after an attempted action is replayed through the receiver-local decision path.
- Timing comparisons use causal barriers, not converted virtual ticks.
- Benign availability effects and performance selections are reported separately from correctness.
- Live execution supplies operational evidence; strict counterfactual conclusions come from replay.
