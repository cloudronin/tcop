## Validator checklist

Each line requires a deterministic failing-case unittest. These are amendment 003 gates, not replacements for G12-G17 or earlier gates.

| Gate | Rejection |
| --- | --- |
| Tightening | Candidate adds any destination, executable grant, scope, inference authority, or lifecycle capability; wrong action cardinality or target; unsupported native operation |
| Immutable admission | Any agent/runtime/preset pin absent, mismatched, or not backed by bytes; same-host topology; baseline mismatch |
| Census | Script absent from sealed census or changed; draft/missing public mapping for non-smoke |
| Live replay | Frozen trace absent or outcome mismatch; mismatches close environment_failure and cannot enter results |
| Arms per cell | Missing namespaced E0/E1/E2 under each family/script/timing cell/seed; E2 modes separately represented |
| Families | Any of S-A/S-B/S-C omitted from result coverage |
| Frontier counts | Either numerator or denominator absent for work or harm; zero denominators must explicitly retain undefined and counts |
| Prediction | Pre-execution expected-pattern seal/hash missing, changed, or attached after execution |
| Approval separation | E2a/E2b pooled or native route/approval setting falsely attributed |
| Effective plan | 1.3/003/ladder missing, legacy lists changed to hold ladder semantics, or unknown manifest version |
| Held-out completion | G12-G17/prior gates incomplete, source roots changed, required timing/replay/coverage evidence missing |
| Smoke exclusion | Smoke promoted to result status, valid_for_results true/missing, reported/extracted as efficacy, or BLOCKED containing numeric findings |

The cannot-widen proof must enumerate **every** candidate in the declared finite representable output space. Define the finite destination names/ports/rule IDs, credential-scope names, sandbox ID, and action discriminants from the admitted manifest. Enumerate all removal subsets and each single-scope/freeze/snapshot candidate, plus every representable invalid additive/grant/unfreeze/exec candidate and wrong target. Assert allowed authority is a subset of the baseline for every accepted output; preserve static/inference authority. Reject unbounded strings, wildcards, unknown values, and unsupported capabilities before submission. Test the serializer/transport boundary too, so a validated action cannot become another RPC or a global write. State the proof boundary: adapter-representable output space, not arbitrary OpenShell policies or runtime correctness. Until native capability gaps are resolved, exhaustive enumeration must prove unsupported candidates are rejected, not claim they executed.
