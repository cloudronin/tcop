## Implemented architecture

- A separate strict `tcx-observation-v0.2` schema and an explicit versioned
  validator dispatcher.
- Receiver-side control-group classification: self assertions and same-control
  reports are retained but reclassified as non-independent evidence.
- Signed interaction receipts, bilateral acknowledgement, unilateral refusal,
  receipt verification, and receipt-gated independent corroboration.
- Immutable relay wrappers, relay-loop rejection, and synchronization-after-
  heal that replays the original signed observation without witness inflation.
- Passive local witnesses that resolve direct observations before attempted TCX
  dissemination, including during a remote partition.
- Safe active patrols with authorization, allowlisted targets, synthetic-data
  scope, TTL, query budget, rate/concurrency configuration, and no direct
  enforcement capability.
- Evidence-aware local resolution, conflict preservation, withdrawal, and
  staged recovery. Withdrawal alone is approval-gated; clean receipt-verified
  evidence completes recovery.
- A faultable central monitor that consumes the same signed input facts,
  receipts, patrol outputs, and `SimulatedResponseAdapter` implementation as
  comparable TCX cases. Its reach, delay, outage, and compromise properties are
  explicit rather than implicit global knowledge.

Every v0.2 run emits the original protocol/resolution/truth streams plus
`witness-graph.json`, `interaction-receipts.jsonl`, `patrol-events.jsonl`,
`control-group-registry.json`, `observer-classification.jsonl`, and
`conflicting-evidence.jsonl`.

- B-029: equal, limited, and unavailable faultable-central controls.

## Controlled findings

These are mechanism outcomes in a synthetic deterministic simulator, not
claims about deployed agents or organizations.

- A direct peer observation with a valid receipt constrains the local receiver
  even while its remote link is partitioned. After the link heals, relayed
  synchronization reaches the isolated node without creating another witness.
- A self-assertion and a ten-process same-control witness farm provide zero
  independent corroboration. Apparent domain diversity does not help when the
  hidden control group is the same.
- A tampered receipt is rejected even when its signer has a valid key. A subject
  can refuse bilateral acknowledgement without erasing unilateral transport
  evidence.
- One receipt-verified independent critical witness creates a narrow
  constraint; two distinct control groups can satisfy the reference
  quarantine threshold. This deliberately exposes a collusion boundary rather
  than claiming collusion resistance.
- A clean patrol result completes recovery only after the triggering claim has
  been withdrawn. Time alone does not restore the normal envelope.
- In B-029, the available equal-reach central monitor and the TCX witness path
  both constrain all five nodes from the same input fact. The modeled central
  outage constrains none, making its five-node failure blast radius explicit.

The aggregate report intentionally does not support a winner claim: each
scenario has its own objective, and mean objective success is only a regression
indicator. The raw matrix is at `artifacts/witness-v0.2/`.

## Deterministic sweep calibrations

The witness profile produces separate coverage, patrol-cadence, collusion,
overlay, and central-fault artifact directories. These current sweeps are
parameterized deterministic calibrations, not empirical performance curves:

- coverage from 0% to 100% maps first-contact exposure from 1.0 to 0.0 while
  message cost rises from 0 to 5 units;
- patrol cadence of 1, 3, and 5 virtual ticks trades time to useful observation
  against cost of 1.0, 0.333, and 0.2 units respectively;
- the reference collusion threshold is two distinct receipt-verified control
  groups, by design, and is reported as an attack boundary rather than a safety
  property.

## Remaining boundary

The v0.2 profile remains entirely deterministic. It intentionally excludes live
LLMs, real clients, production credentials, real network transport, scanning,
or enforcement. The next research question is not deployment; it is whether
more realistic deterministic interaction graphs, patrol schedules, and central
failure/compromise models change these controlled boundaries.
