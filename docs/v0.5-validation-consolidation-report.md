# TCOP v0.5 validation and consolidation

This pass audits the frozen deterministic v0.5 study before v0.6. It adds no
TCOP mechanism, protocol field, trust state, policy tuning, or scenario. Its
machine-readable output is isolated beneath `artifacts/minimality-v0.5-validation/`.

## Validation conclusions

- `P2` and `F-00000000` are exact runtime equivalents: distinct manifest IDs
  with the same enabled feature composition. Pareto frontiers therefore label
  them `equivalent`, never as dominators of one another.
- `P1` is an inactive static-policy baseline in the frozen study: no policy
  feature or native policy backend is enabled. Equality with `P0` is not a
  finding about static-policy effectiveness.
- The receipt leave-one-out effect is real in the measured corpus, but it
  removes the receipt-dependent tip, budget, and reserve closure. The S3-only
  `I-02` probe is not an isolated receipt test and does not contradict that
  result.
- I-05 coverage labels do not modify the composed profile or the shared input
  facts. In addition, some patrol-disabled confirmation rows retain the frozen
  patrol-capable backend. These results are classified as activation/wiring
  limits rather than patrol preventive neutrality.
- `F-10111100` matches P7 aggregate outcomes but is not presented as a P7
  equivalent unless the per-scenario response and intermediate-trace evidence
  says so. The same rule is applied to every reduced candidate.

## Frozen v0.6 admission set

Only these objective-specific, pre-executed profiles are frozen for the
deterministic federated-domain study:

1. `containment-first` — P2, canonical representative of the P2 alias class.
2. `balanced` — the jointly reduced, dependency-valid composition, exact-runtime-equivalent
   to F-10111100 and evaluated against P7 per scenario.
3. `utility-preserving` — F-10110000, evaluated against P5 and P7.
4. `forensic-extension` — P7, retained only as a separately justified
   assurance/audit extension.

The jointly reduced validation composition is evidence for consolidation, not
an additional v0.6 admission profile.

Run the pass with:

```sh
make research-minimality-validation
```

The command verifies schemas and tests, reads `artifacts/minimality-v0.5/`,
re-executes only candidate compositions in temporary storage, and writes the
new reports and immutable profile manifests to the validation root.
