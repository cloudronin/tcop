# TCOP v0.6 deterministic federation harness

v0.6 is an outer evaluation harness around frozen v0.1–v0.5 behavior. It does not add a TCOP wire field, evidence class, trust state, reliability rule, patrol, remote enforcement call, or real-agent dependency.

The harness freezes phase ordering and separates authored scenario facts, benchmark truth, signed observations, transport/fault records, and derived outcomes. Benchmark truth is only visible to A5.

`A1` and `A2` share authored telemetry, observer timing, local strategy, enforcement adapter, and non-TCOP network conditions. A2's only extra input is receiver-validated gateway deliveries. A3 consumes a canonical copy of the same exportable bounded-fact stream used by A2; it is not independently regenerated.

Run the complete deterministic study with:

```sh
make research-federated-v0.6
```

All output is written below `artifacts/federated-domain-v0.6/`. The target first certifies the four admissible v0.5 profile manifests and then runs smoke conformance, exact replay, the pre-registered matrix, reports, and artifact verification.
