# Anonymous Reviewer Artifact

This directory is the compact anonymous reviewer package for the TCOP paper. It contains machine-checkable expected results, normalized data, figure and table provenance, and a credential-free reproduction driver. It intentionally does not include any provider credential or full raw research artifact tree.

For Tier 1 and Tier 2, distribute this directory with an anonymous TCOP source-and-artifact archive that preserves the repository-relative source paths. Tier 0 can inspect expected results and all derived paper material directly.
