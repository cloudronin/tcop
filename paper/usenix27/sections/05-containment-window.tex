\section{Containment Windows and Outcome Accounting}

A warning can change an outcome only if it becomes actionable before the affected authorization boundary. This action-relative \emph{containment window} can close for a completed action while remaining open for a later one. Figure~\ref{fig:containment-window} distinguishes prospective blocking, subsequent blast-radius reduction, and late evidence useful only for coordination or forensics.

\begin{figure}[t]
\centering
\includegraphics[width=\columnwidth]{containment-window}
\caption{Action-relative containment-window regimes. A warning can be too late for one action and still be actionable for a later one.}
\label{fig:containment-window}
\end{figure}

An alert, evidence receipt, or policy change alone is not a causal improvement. Credit requires accepted evidence, a bound local subject, local policy evaluation and decision, and a changed gateway disposition for the same action opportunity. Late evidence never reverses completed harm. Reference-path and replay studies vary delivery timing while fixing the synthetic action sequence.
