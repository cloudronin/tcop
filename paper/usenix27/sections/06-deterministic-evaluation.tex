\subsection{Context versus blanket restriction}

The separately rooted context-value comparator holds receiver enforcement and warning arrival fixed across local-only (C0), arrival-only blanket restriction (C1), validated context matching (C2), and always-restrict (C3). C1 receives only a valid-arrival token and TTL; C2 additionally evaluates validated issuer, receipt, subject, resource namespace, capability class, scope, and expiry against receiver-local authorization state. The frozen cohorts contain no episode that combines a matching harmful action with a nonmatching benign action in the same guarded capability class, so the primary selectivity comparison is an explicitly separate deterministic policy fixture. There, C1 and C2 both prevent the matching harmful write, while C1 constrains the nonmatching benign write and C2 forwards it. C3 remains the security-availability frontier. The exhaustive rows, field-use traces, controls, and unpooled cohort outcomes are in the comparator artifact.
