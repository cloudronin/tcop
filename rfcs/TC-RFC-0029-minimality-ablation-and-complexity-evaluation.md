# TC-RFC-0029: TCOP minimality, ablation, and complexity evaluation (Draft)

Minimality evaluation SHALL retain raw per-family security, utility,
operational, and complexity records before calculating aggregate scores.
Comparisons SHALL use identical content-addressed environment and protocol
input. Benchmark truth remains unavailable to runtime profiles.

Complexity counting rules and integer cost-model weights SHALL be checked in
before the study. Pareto frontiers exclude protocol-invalid negative controls.
Feature reports SHALL distinguish preventive value from forensic or assurance
value and preserve negative or dominated findings.
