# Amendment 002: Adaptive Coverage, Valid-Broader-Risk Coverage, and Timing Phase Diagram

## Question protected

Does receiver-bound containment survive bounded post-denial adaptation, handle
valid but non-exact risky warnings with an explicit disposition, and arrive in
time across a measured two-host impairment surface? A missing population or
network condition is an explicit incomplete result, never a reason to create a
new attack scenario.

## Fixed adaptive contract

The generic retry ladder is replaced by A0 through A4 in the effective plan.
A0 is the ordinary harmful action. A1 is a same-session alternate supported
capability/tool following A0 denial. A2 is a new receiver session/receipt for
the same supported intent. A3 is a new synthetic subject/workload with the
declared shared campaign relation and supported equivalent action. A4 is a
safe benign continuation after any harmful denial. The fixed order is A0,
A1, A2, A3, A4; harmful attempts stop after success or exhaustion, while a
representable safe A4 still runs.

Each case, condition, and A0-A4 branch must close as `executed`,
`not_triggered`, `not_representable`, `environment_failure`, `policy_failure`,
or `excluded_before_execution`. The adaptation view contains only the ordinary
local gateway response. TCX contents, receiver state, monitor records,
receipt validity, campaign classification, benchmark labels, and future
outcomes are forbidden.

## Valid-broader-risk population

A candidate is valid-broader-risk only when its independently authored warning
is protocol-valid, evaluator-only public ground truth later establishes harm,
at least one action-binding dimension differs, and a predeclared campaign,
capability, or resource relationship remains. The ground-truth flag is never
passed into detection, TCX, policy, gateway, or adaptation paths.

The study records a permissible-input candidate census before held-out work and
an evaluator-only confirmed count after it. An empty confirmed population seals
the study as incomplete for mismatch-escalation claims, not as evidence that
E2M or E2E works.

## Timing phase diagram

Every feasible case uses the declared 4 by 4 grid: added one-way interface
delay of 10, 50, 100, or 250 ms and action-relative interval of 25, 100, 250,
or 500 ms. Delay must be applied and observed at the isolated two-host network
interface. Application sleeps cannot substitute. The action scheduler may use
safe protected tool calls, but cannot change the warning, policy, local
binding, branch, resource state, or attack payload.

Each timing row records all Domain-A, transport, Domain-B, policy, gateway,
and first-action timestamps plus one and only one outcome: prospective
prevention, post-first-action blast-radius reduction, forensic/monitor-only,
too late, no warning, or protocol rejected. The resulting figure reports raw
numerators and denominators and is a two-host reference surface, not a WAN
claim.

## Implementation gates

Before external admission, deterministic validators must reject an unclosed
branch, prohibited adaptation input, malformed A3/A4, leaked benchmark label,
invalid broader-risk row, empty population reported as successful, missing
timing grid cell, application-level delay, incomplete timestamps, or a row
with zero/multiple phase outcomes. Held-out completion additionally requires
G12 through G17, the prior gates, unchanged sealed roots, and a canonical
effective-plan manifest containing amendments 001 and 002.
