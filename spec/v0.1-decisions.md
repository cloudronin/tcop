# TCOP v0.1 normative implementation decisions

These decisions make the research draft executable without claiming to settle
future TC-RFCs.

1. The v0.1 wire encoding is canonical JSON: UTF-8, object keys sorted by
   Unicode code point, compact separators, and no insignificant whitespace.
2. The signature covers the complete envelope after removing only `signature`.
   The reference cryptographic profile is Ed25519.
3. Discovery is a static, local authority registry. It is configuration, not a
   remote trust verdict.
4. Every observation uses RFC3339 UTC timestamps, an expiration time, and a
   monotonic sequence per observer and subject.
5. The default simulated TTL is 60 seconds and default clock-skew allowance is
   5 seconds. Profiles must make deviations explicit.
6. Resolution produces capability-specific envelopes. A remote decision or
   score is never an input to the protocol.
7. Benchmark ground truth is inaccessible to protocol, resolver, and response
   packages.
8. No global trust-state convergence is required. Benchmarking measures context
   dissemination, local state stabilization, and policy compatibility instead.
