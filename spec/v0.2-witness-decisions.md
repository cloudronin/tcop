# TCOP v0.2 deterministic witness-profile decisions

1. TCX v0.2 is a parallel profile. It does not alter v0.1 envelope validation,
   benchmark identifiers, artifacts, or regression digests.
2. Evidence class is a receiver-generated classification based on the
   control-group registry; a signed self-declaration is not authoritative.
3. The default profile requires a valid interaction receipt before independent
   peer or neutral-patrol evidence contributes corroboration.
4. Receipt acknowledgements prove interaction occurrence only. Receipt refusal
   remains auditable unilateral evidence.
5. Passive direct observations resolve locally before dissemination and remain
   usable during a remote partition.
6. Relays preserve the original signed envelope and never add independent
   witness credit. Synchronization after heal is a relay operation.
7. Patrols are static-authorized, synthetic-data-only, budgeted observers; they
   never call enforcement adapters directly.
8. The resolver preserves conflict and uses staged recovery. Time alone cannot
   restore high-risk capabilities to the normal envelope.
9. Central controls consume the same signed fact set, receipt registry, patrol
   results, and simulated response adapter type as comparable TCX controls.
   Reachability, processing delay, outage, and compromise are explicit faults.
10. Scenario objectives remain separate. Aggregate objective success is a
    regression signal, never a universal attack-success metric.
