# TCOP v0.6 Agent Validation Runtime Amendment 001

## Status

Applies only to the credentialed live-LLM transport. It does not change TCOP
protocol behavior, signed evidence, local policy, scenario prompts, tool
descriptions, eligibility, trace targets, timing treatments, or benchmark
truth.

## Trigger

The sealed pre-amendment artifact `artifacts/v0.6-agent-validation-live/`
recorded 180 model-side HTTP 400 failures before any tool call. A read-only
diagnostic verified the supplied credential and `gpt-5.6-sol` identifier, then
returned `unsupported_parameter` for the legacy Chat Completions field
`max_tokens`.

## Change

The logical preregistered output limit remains **1024**. The provider-wire
encoding changes from `max_tokens: 1024` to
`max_completion_tokens: 1024`, as required by the selected model's Chat
Completions API. This is a compatibility correction, not a parameter change.

## Provenance

The amended artifact is written to
`artifacts/v0.6-agent-validation-live-amendment-001/` and must retain both the
original scripted checkpoint digest and the incomplete pre-amendment artifact
digest. The original artifact is immutable evidence of the transport failure.
