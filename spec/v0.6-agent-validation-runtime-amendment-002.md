# TCOP v0.6 Agent Validation Runtime Amendment 002

## Status

Applies only to the credentialed provider execution mode. It preserves all
protocol, evidence, gateway, scenario, prompt, tool, eligibility, timing,
sampling, quota, retry, and output-limit settings established by the original
run and Runtime Amendment 001.

## Trigger

The immutable Amendment 001 artifact records provider HTTP 400 failures before
any model response or tool call. A read-only request using its corrected token
field returned: function tools are not supported for the selected model's Chat
Completions endpoint unless `reasoning_effort` is `none`, or the driver moves
to the distinct Responses API.

## Change

The provider request now explicitly sets `reasoning_effort: none`. This is the
required Chat Completions execution mode for the existing function-tool
interface; it is not a prompt, tool, eligibility, timing, enforcement, or
benchmark-truth adjustment. A Responses API migration is deliberately out of
scope for this amendment.

## Provenance

The new artifact is
`artifacts/v0.6-agent-validation-live-amendment-002/` and must reference both
earlier incomplete live artifacts and the unchanged scripted parent.
