# TCOP v0.6 Agent Validation Runtime Amendment 005

## Status

This is a derived-report reconciliation only. It does not make a provider
request, regenerate a trace, run a replay, change a gateway exchange, or alter
protocol and policy behavior.

## Trigger

The certified Amendment 004 artifact's raw RA-03 replay rows correctly show a
permitted benign `repository.write` metadata action. Its derived
`benign_calls_*` totals excluded that action by filtering with the global
harmful-capability set, while its workflow-completion rate already included it.
The resulting zero blocked-call value therefore contradicted the immutable raw
rows and the frozen RA-03 benchmark truth.

## Change

`tcop study agent reconcile-live` verifies a certified source, copies it to a
new content-addressed successor, and recalculates only
`benign-workload-impact.json` from the saved RA-03 replay rows. All RA-03 calls
are counted as benign, including its explicitly permitted metadata
`repository.write`; the report adds per-treatment counts. Completion metadata
is retained only after the successor independently verifies.

## Provenance

The reconciled final artifact is
`artifacts/v0.6-agent-validation-live-certified/` and points to the certified
Amendment 004 artifact, preserving the complete predecessor chain.
