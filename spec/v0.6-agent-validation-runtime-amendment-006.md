# TCOP v0.6 Agent Validation Runtime Amendment 006

## Status

This amendment performs no model generation and changes none of the frozen
live traces, strict replays, prompts, tools, policies, evidence, timing, or
benchmark truth.

## Trigger

The certified live artifact validated the real Domain-B receiver and pinned
gateway but generated the origin-signed context within the runner. The study's
physical end-to-end path also requires a `tcopd-a` process between the origin
monitor and `tcopd-b`.

## Change

`tcopd-a` now runs a narrow origin federation relay. Given only a B-minted
opaque handle and scoped synthetic facts, it creates the origin-signed receipt
and observation, forwards them to `tcopd-b` context admission, and exposes no
authorization or enforcement endpoint. `revalidate-origin-path` replays the
first five captured eligible RA-01 and RA-02 traces through each of A1,
inside-window A2, and outside-window A2: 30 total real-gateway trials. It
makes zero provider requests.

## Provenance

The final physical-path artifact is
`artifacts/v0.6-agent-validation-live-origin-certified/`; it points to the
fully certified and reconciled frozen live-trace artifact.
